2

パソコン（Windows）で起動する

  1. パソコンにある 「AMO工程表.exe」をダブルクリックします。
  2. 黒い小さなウィンドウが開き、「起動しました」「接続用URL」が表示されます。
    ⚠ このウィンドウは閉じないでください（閉じるとアプリが止まります）。
    同時に、このPCの画面でアプリが自動で開きます。
  3. 初回だけ、Windowsが「このアプリにアクセスを許可しますか？」と聞いてきます。
    → 「アクセスを許可」を押してください（iPad/iPhoneからつなぐために必要です）。
C:\AMO> AMO工程表.exe
✔ 起動しました
→ 接続用URL: http://192.168.1.5:8080
(このウィンドウは閉じないでください)
▲ 黒いウィンドウの表示イメージ
💡 ポイント
データはexeと同じ場所の data\koteihyo.json に自動保存されます。保存ボタンは不要です。

iPad / iPhone をつなぐ（QRコード）

  1. アプリ右上の 「接続」を開きます。
  2. 大きなURLとQRコードが表示されます。
  3. iPad / iPhone をパソコンと同じWi-Fiにつなぎます。
  4. カメラでQRコードを読みます（またはURLを手入力）。
  5. 同じ画面がiPad / iPhoneに開きます。
QRコード
📶 同じWi-Fiでつないでね
パソコンとiPadが別のWi-Fiだと、つながりません。

💡 ポイント
パソコンのアプリ（黒いウィンドウ）を起動したままにしておけば、iPad・iPhone・別のPCのどれからでも同じデータを見て編集できます。

基本の使い方 — ＋／−で数える いちばん大事

  1. カレンダー（最初の画面）で日付をタップ → その週の表が開きます。
  2. 表は「工程（たて）× 曜日 月〜日（よこ）」になっています。
  3. あるお客さんにシャンプーをしたら、その曜日のシャンプー欄の「＋」を1回押す ＝ 1件。
  4. 間違えたら「−」で1件減らせます（0より下にはなりません）。

▲ 表のイメージ — ＋はローズ色、−は白
💡 ポイント
＋と−のボタンは大きめに作ってあるので、iPadでもタッチしやすいです。

「カレンダー」でいつでも別の日付へジャンプ。

◀ 前週 6/2 〜 6/8 次週 ▶ 今週
▲ 週の移動ボタン

スタッフの切り替え

上の「スタッフ」タブで担当者を切り替えます。スタッフごとに自分の表があります。

小池 井上 浜田
▲ スタッフタブのイメージ

備考

表の一番下に「備考」があります。その日のメモを書けます（自動保存）。

6

合計の見方（自動計算）

表の下に「日別合計」（曜日ごとの件数・売上）が出ます。

さらに下に2つのカードがあります：

小池 さんの週合計
42件 / ¥28,400
全体（全スタッフ）週合計
126件 / ¥85,200

どちらも件数と売上（単価×件数）が表示されます。
白いカード＝選んでいるスタッフ、黒いカード＝お店全体の合計です。

戻る・元に戻す・履歴

大事な区別があります：

←
戻る
ひとつ前の画面に戻るだけ
⟲
元に戻す
直前の操作を取り消す
（何回でも前に戻れる）
⟳
やり直し
取り消したのを
もう一度やる

元に戻すと、何を戻したかが表示されるので安心です。

✅「浜田 6/8 シャンプー +1」を元に戻しました
▲ 元に戻したときの表示

履歴画面

「履歴」画面では、いつ・誰が・何をしたか（＋1、名前変更 など）を日付ごとにすべて記録しています。消えません。

各記録の「ここまで戻す」で、その時点の状態まで戻せます。

CSV書き出し・印刷（紙の代わり）

  1. 「設定」の下にある「書き出し・印刷」を開きます。
  2. 開始日〜終了日を選びます。
  3. 「CSV書き出し」＝ Excelで開ける表として保存（日本語OK）。
  4. 「印刷」＝ そのまま紙に印刷できます。

データの保存・バックアップ・引っ越し

保存先

📁 AMO工程表のフォルダ
  ├ AMO工程表.exe
  └ 📁 data
      └ koteihyo.json ← これがデータ

バックアップ

koteihyo.json をUSBメモリやクラウド（OneDriveなど）にコピーしておけば安心です。

PCを買い替えたとき

新しいPCに exe を置き、data\koteihyo.json を同じ場所にコピーするだけ。全部のデータがそのまま使えます。

困ったとき（Q&A）

iPad / iPhone で開けない
次を順に確認してください：
ⓐ パソコンと同じWi-Fiにつないでいるか
ⓑ パソコンのアプリ（黒いウィンドウ）が起動中か
ⓒ 初回の「アクセスを許可」を押したか
ⓓ 「接続」画面の最新のURL / QRコードを使っているか
起動するたびにURLの数字（ポート）が変わる
前回の番号がまだ使用中のときに起こります。
→ 「接続」画面の"今のQR / URL"を使えばOKです。
黒いウィンドウを閉じてしまった
アプリが止まっただけです。データは消えません。
→ もう一度 exe をダブルクリックすれば再開します。
＋を押しても変わらない / 反応が遅い
→ 少し待ってから、画面を再読み込み（ブラウザの更新ボタン）してみてください。
