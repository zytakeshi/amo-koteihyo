パソコン（Windows）で起動する

  1. 上の 「アプリをダウンロード（zip）」から AMO-koteihyo-windows.zip を保存します。
  2. 保存したzipを 右クリック →「すべて展開」 で展開します。
    中に AMO-koteihyo.exe と ファイアウォール許可.bat の2つが入っています。
  3. はじめに1回だけ： 「ファイアウォール許可.bat」を右クリック →「管理者として実行」します。
    「許可しますか？」が出たら 「はい」 を押してください（iPad/iPhoneからつなぐために必要です）。
  4. 「AMO-koteihyo.exe」をダブルクリックして起動します。
  5. 黒い小さなウィンドウが開き、接続用URLが表示されます。
    ⚠ このウィンドウは閉じないでください（閉じるとアプリが止まります）。
    同時に、このPCの画面でアプリが自動で開きます。
💡 ポイント
「ファイアウォール許可.bat」は最初の1回だけでOK。2回目以降は AMO-koteihyo.exe をダブルクリックするだけで使えます。
※ 2つのファイルは同じフォルダに置いたままにしてください（batがexeを許可するため）。
C:\AMO> AMO-koteihyo.exe
✔ 起動しました
→ 接続用URL: http://192.168.1.5:8080
(このウィンドウは閉じないでください)

💡 ポイント
データはexeと同じ場所の data\koteihyo.json に自動保存されます。保存ボタンは不要です。

基本の使い方 — ＋／−で数える いちばん大事

  1. カレンダー（最初の画面）で日付をタップ → その週の表が開きます。
  2. 表は「工程（たて）× 曜日 月〜日（よこ）」になっています。
  3. あるお客さんにシャンプーをしたら、その曜日のシャンプー欄の「＋」を1回押す ＝ 1件。
  4. 間違えたら「−」で1件減らせます（0より下にはなりません）。

履歴画面

「履歴」画面では、いつ・誰が・何をしたか（＋1、名前変更 など）を日付ごとにすべて記録しています。消えません。

各記録の「ここまで戻す」で、その時点の状態まで戻せます。

タイムカード（出勤・退勤・休憩） 新機能

紙のタイムカードの代わりに、出勤・退勤・休憩をこのアプリで打刻できます。工程表と同じデータ・同じ URL / QR で使え、同じ「元に戻す・履歴」も効きます。

上のメニューの 「タイムカード」を開くと、「打刻」と「月次」の2つのタブがあります。

打刻タブ（入口の iPad 向け）

  1. 大きな時計と、スタッフごとのボタンが並びます。
  2. 出勤したら自分の「出勤」を押すだけ（時刻はパソコンの時計で自動記録）。
  3. 休憩に入る時は「休憩開始」、戻ったら「休憩終了」（何回でも）。
  4. 帰る時は「退勤」。押せるボタンだけが表示されます。
打刻 月次
7月18日(土)　14:23:07
⚠ 7/17 浜田さんの退勤打刻がありません
小池 勤務中 09:58〜 休憩開始 退勤
井上 休憩中 12:30〜 休憩終了
▲ 打刻タブのイメージ
💡 前の日の退勤を押し忘れたら
夜をまたいで退勤し忘れた時は、翌日そのスタッフに 「退勤（前日分）」ボタンが出ます。押すと前日の退勤として記録されます（時刻は 23:59 として印が付きます）。直したい時は「月次」の ✎ で修正できます。

月次タブ（集計・修正・書き出し）

スタッフと月を選ぶと、その月の出勤・退勤・休憩・実働時間が一覧で出ます。退職・無効にしたスタッフでも、その月に打刻があれば 退職/無効 の印付きで表示され、給与のための修正ができます。

  • 各行の ✎ を押すと、その場で時刻・休憩・勤怠メモを直せます（保存すると履歴に残ります）。
  • 「CSV」で Excel 用に書き出し、「印刷」で今表示中のスタッフの月表を紙に印刷できます。
💡 丸め表示は「参考」だけ
「設定」の「タイムカード設定」で、実働時間の丸め表示（5分・15分など）や所定労働時間を決められます。ただし給与計算に使う数字は、常に丸めていない実測値です。丸めた値はあくまで参考表示で、初期設定は「丸めなし」です。

アプリの自動アップデート

新しいバージョンが出ると、カレンダー画面の上に案内が表示されます。

新しいバージョン v1.1.0 があります 今すぐ更新 あとで
▲ 更新のお知らせ（カレンダー画面）
  1. 「今すぐ更新」を押すと確認が出ます。更新中は全員のアプリがいったん止まり、約10秒で自動的に再開します。
  2. 更新の間は「更新中… そのままお待ちください」の画面になります。終わると自動で新しい画面に切り替わります。
  3. 今はまだ更新したくない時は「あとで」。次に開いた時にまた案内されます。
💡 データはそのまま引き継がれます
更新してもタイムカードや工程表のデータはそのまま残ります。バックアップは、タイムカード対応版へ初めて上げた時に一度と、毎日はじめての保存時（過去14日分を自動で保存）に作られます（data\backup\ の中）。もし古い版に戻す時は、この中の同じ日付のバックアップから復元してください。
⚠ 最初の一回だけ手動更新
今 v1.0.0 をお使いの場合、v1.1.0 へは新しい exe を手でダウンロードして置き換えるのが最後の手作業です（v1.0.0 には自動更新機能がまだ無いため）。v1.1.0 以降は、上の「今すぐ更新」で自動更新できます。
💡 更新が進まない時
90秒たっても画面が切り替わらない時は、パソコンの黒いウィンドウを確認してください。指示が出ていれば、その通りに AMO-koteihyo.exe をダブルクリックし直せば元に戻せます（更新前のアプリは AMO-koteihyo.exe.old として残っています）。

ファイアウォールを再び有効にする手順

「つなぐために一時的にファイアウォールを切っていた」場合でも、ファイアウォールは必ず「オン」に戻してください。オンのままでも、このアプリだけを許可すれば iPad / iPhone から使えます。

  1. Windows の「Windows セキュリティ」→「ファイアウォールとネットワーク保護」で、ファイアウォールをオンに戻します。
  2. アプリのフォルダの 「ファイアウォール許可.bat」を右クリック →「管理者として実行」します（「はい」を押す）。
    　または AMO-koteihyo.exe を一度起動して、出てきた「許可しますか？」で「はい」を押すだけでもOKです。
  3. iPad / iPhone で「接続」画面の URL / QR を開き、つながることを確認します。
💡 なぜ .bat とアプリのどちらでも良いの？
「ファイアウォール許可.bat」とアプリはまったく同じ許可ルールを作ります。どちらで許可しても、アプリはそのルールを正しく認識します。
🔧 それでもつながらない時のチェック（詳しい人向け）
・Windows Defender ファイアウォールで「すべての受信接続をブロック」（blockinboundalways）がオンになっていないか。オンだと、個別の許可ルールがあっても受信が遮断されます。
・このアプリを明示的にブロックするルールが別に作られていないか（許可より優先されます）。
・会社のグループポリシーで「ローカルのファイアウォール規則を結合しない」設定になっていないか。
・パソコンと iPad が同じ Wi-Fi（同じネットワーク）か。
📌 SmartScreen が出た時（別の話）
起動時に青い画面で「WindowsによってPCが保護されました」が出たら、「詳細情報」→「実行」で起動できます。これはファイアウォールとは別の仕組みで、アプリの実行を確認しているだけです。
⚠ ファイアウォールやウイルス対策ソフトは「切らない」でください。
つながらない原因のほとんどは「このアプリを許可していないだけ」です。上の手順でアプリを許可すれば、保護をオンにしたまま安全に使えます。

困ったとき（Q&A）

iPad / iPhone で開けない
次を順に確認してください：
ⓐ パソコンと同じWi-Fiにつないでいるか
ⓑ パソコンのアプリ（黒いウィンドウ）が起動中か
ⓒ 初回の「許可しますか？」で「はい」を押したか（押しそびれたら zip の「ファイアウォール許可.bat」を管理者として実行）
ⓓ 「接続」画面の最新のURL / QRコードを使っているか
起動するたびにURLの数字（ポート）が変わる
前回の番号がまだ使用中のときに起こります。
→ 「接続」画面の"今のQR / URL"を使えばOKです。
黒いウィンドウを閉じてしまった
アプリが止まっただけです。データは消えません。
→ もう一度 exe をダブルクリックすれば再開します。
＋を押しても変わらない / 反応が遅い
→ 少し待ってから、画面を再読み込み（ブラウザの更新ボタン）してみてください。
