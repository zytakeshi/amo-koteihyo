新しいバージョンへの かんたん更新

いま使っているアプリを、新しいバージョンにします。
むずかしい操作はありません。ボタンを押して、ダブルクリックするだけ。
データ（打刻・工程表）は消えません。
⬇ かんたんアップデートを ダウンロード

ダウンロードした AMO-koteihyo-update.bat をダブルクリックするだけです。

下に手順があります ↓

1

4ステップで更新できます

①

「かんたんアップデート」をダウンロード

下のボタンを押すと、更新用のファイルが1つダウンロードされます。

⬇ ダウンロード

ファイル名：AMO-koteihyo-update.bat（ふつうは「ダウンロード」フォルダに入ります）

②

ダウンロードしたファイルを ダブルクリック

ダウンロードした AMO-koteihyo-update.bat をダブルクリックします。

※ このとき、青い警告画面や、ブラウザの「このファイルを保存しますか？」が先に出ることがあります。出たら、あわてずに次の③へ進んでください。

③

青い画面や警告が出たら「詳細情報」→「実行」

「WindowsによってPCが保護されました」という青い画面が出ることがあります。あわてなくて大丈夫です。（お使いのパソコンの設定により、表示やボタンの文言は少し変わります。）

WindowsによってPCが保護されました
Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました…
詳細情報 ← まずここを押す
実行 ← 次にこのボタンが出るので押す

「詳細情報」を押す → 下に「実行」ボタンが出る → 「実行」を押す、の順です。
ブラウザ側で「保持する／保存」を聞かれたら、「保持する」を選んでください。

④

黒い画面に完了メッセージが出て、新しいアプリが自動で開きます

「実行」を押すと黒い画面が開き、自動で更新がはじまります。途中で閉じずにお待ちください。
黒い画面に「更新が完了しました！」と出たら成功です。そのまま新しいバージョンのアプリが自動で開きます。

************************************************************
*        更新が完了しました！                       *
************************************************************
新しいアプリの黒いウィンドウが自動で開きます。
このウィンドウは閉じて大丈夫です。

この黒い画面は、読んだあとは閉じて大丈夫です。

2

データは消えません

更新しても、これまでの打刻・工程表・設定はそのまま残ります。安心してお使いください。

🛡 自動でバックアップします
更新のときに、古いアプリは同じフォルダに AMO-koteihyo.exe.old-v1.0.0（以前の名前が AMO工程表.exe だった場合は AMO工程表.exe.old-v1.0.0 も）という名前で残します（消しません）。
既存の koteihyo.json はこの更新ツールでは変更しません。新しいアプリが初回起動時に、安全のための控え data\backup\koteihyo.pre-v1.1.0.json を自動で作成します。
🔗 今までのショートカットもそのまま使えます
以前 AMO工程表.exe のショートカットを使っていた場合でも、更新後は同じ名前でも新しいバージョンが開くようにしてあります。デスクトップのショートカットは、そのままでOKです。
3

困ったとき

黒い画面が一瞬で消えてしまった
何かのエラーで途中で閉じた可能性があります。データは無事です。
→ もう一度 AMO-koteihyo-update.bat をダブルクリックしてみてください。
→ それでも消えてしまう場合は、そのままの状態で連絡してください。
更新したのに、まだ古いバージョンのまま
アプリを一度閉じてから開き直すと、新しい画面になることがあります。
→ それでも変わらない・エラーが出る場合は、無理に操作せず連絡してください。古いアプリは残してあるので、元の状態にすぐ戻せます。
📞 うまくいかないときは
無理に何度もやり直さず、画面をそのままにして連絡してください。
今のアプリは残してあるので、いつでも元に戻せます。データが消えることはありません。
4

この手作業は、今回だけです

今回のこの更新は最初の一回だけの手作業です。

✨ 次回からはワンタップ
新しいバージョンが出ると、アプリのカレンダー画面の上に案内が出ます。
そこの 今すぐ更新 を押すだけで、これからはアプリの中だけで自動更新できます。
