# AMO BARBER 工程表

AMO BARBER 用の社内「工程表」アプリです。これまで紙の週間グリッドで集計していた
「工程（メニュー）× 曜日 × 件数」を、ダブルクリック起動の単体アプリで入力・集計します。

- データはその PC のファイルに保存されます（外部サーバーなし）。
- 同じ Wi-Fi（LAN）内の iPad / iPhone / 他の PC のブラウザからも、表示される
  URL または QR コードで同じデータにアクセス・操作できます。
- 工程ごと・スタッフごとの件数と売上（単価 × 件数）を自動集計します。
- **タイムカード**（出勤・退勤・休憩）を同じアプリ・同じデータで打刻でき、月次集計・CSV・
  印刷・打刻修正（履歴付き）に対応します。給与計算は常に実測（丸めなし）の値を使います。
- **自動アップデート**（GitHub Releases）に対応。新版が出るとカレンダー画面に案内が出て、
  ワンクリックで更新・自動再起動します（v1.1.0 以降）。
- 操作はすべて履歴に残り、「元に戻す（何回でも）」「やり直し」「その時点まで復元」ができます。

技術: Go 標準ライブラリのみ + JSON ファイル保存。フロントは素の HTML / CSS / JS。

## ビルド方法

Go 1.26 以上が必要です。

### Windows 用 .exe を作る（macOS / Linux からクロスコンパイル）

```sh
bash build/build-windows.sh
```

生成物: `build/AMO-koteihyo.exe`
これを Windows PC にコピーして使います。

### この端末用にビルドする

```sh
go build -o koteihyo .
```

## 起動方法

### Windows

`AMO-koteihyo.exe` をダブルクリックします。
黒いコンソール画面に接続 URL が表示されます（このウィンドウは閉じないでください）。
既定ブラウザが自動で開きます。

### コマンドラインから

```sh
go run .            # 開発時にそのまま起動
./koteihyo          # ビルド済みバイナリを起動
```

オプション:

- `-port 8080` … 待ち受けポート（既定 8080。使用中なら +1 して空きを自動で探します）。
- `-open=false` … 起動時のブラウザ自動オープンを抑止します。

起動すると、同一 LAN 用の URL（例 `http://192.168.x.x:8080`）が表示されます。
iPad / iPhone はこの URL を開くか、画面の QR コードを読み込んでアクセスします。

## データ保存場所

実行ファイルと同じフォルダの `data/koteihyo.json` に保存されます。

- 保存は一時ファイルに書き出してから置き換える方式（atomic）で、破損しにくくなっています。
- 操作の都度、自動保存されます（明示的な保存ボタンは不要）。
- 初回起動時、ファイルが無ければ初期データ（7 工程 + 単価、スタッフ 3 名：小池・井上・浜田）を投入します。
- バックアップしたい場合は、この `data/koteihyo.json` をコピーしてください。

> `go run .` で起動した場合など、実行ファイルがビルド一時フォルダにあるときは、
> 代わりにカレントディレクトリ直下の `data/koteihyo.json` を使います。
> また、実行ファイルと同じフォルダに `data/` を作成・書き込みできない場合（例: 読み取り
> 専用の Program Files 配下）は、ユーザー設定フォルダ（`%AppData%\AmoKoteihyo\` 等）に
> フォールバックして保存します。実際の保存先は起動時の黒いウィンドウに表示されます。

## はじめての設定（Windows）

1. `AMO-koteihyo.exe` をデスクトップなど分かりやすい場所に置いてダブルクリック。
2. 初回に Windows ファイアウォールの確認が出たら **「アクセスを許可」** を押す
   （iPad / iPhone から接続するために必要）。
3. アプリ右上の **「接続」** に表示される URL / QR コードを iPad・iPhone で開く
   （※ PC と同じ Wi-Fi につなぐこと。PC のアプリ＝黒いウィンドウは起動したままに）。

## PC を買い替えたとき（データ移行）

新しい PC に `AMO-koteihyo.exe` を置き、旧 PC の `data\koteihyo.json` を
**新 PC の exe と同じ場所の `data\` フォルダ**にコピーするだけで、全データが移ります。

## タイムカード（出勤・退勤・休憩）

上部メニューの **「タイムカード」** から使います。

- **打刻タブ**: 大きな時計とスタッフ別のボタン。時刻はサーバー（この PC）の時計で記録され、
  クライアントは時刻を送りません。出勤 → 休憩開始/終了（複数回可）→ 退勤。押せるボタンだけ
  が有効になります。夜をまたいだ退勤忘れは翌日「退勤（前日分）」で 23:59 として記録されます。
- **月次タブ**: 月・スタッフを選ぶと出勤/退勤/休憩/実働の一覧。`✎` で打刻修正（履歴に残る）、
  CSV 書き出し・印刷ができます。退職/無効スタッフもその月に打刻があれば表示されます。
- **設定 → タイムカード設定**: 実働時間の丸め表示（参考・初期は「なし」）と所定労働時間。
  **給与に使う数字は常に実測（丸めなし）**で、丸め値は参考表示だけです。

すべての打刻・修正は既存の履歴（元に戻す / やり直し / その時点まで復元）に載ります。

## 自動アップデート（GitHub Releases）

新しいリリースが出ると、カレンダー画面上部に案内が表示されます。**「今すぐ更新」**で
ダウンロード → 検証（SHA-256）→ 差し替え → 自動再起動（全端末で約 10 秒）まで行います。

- 取得元は GitHub Releases（`zytakeshi/amo-koteihyo`）。リポジトリ／リリースが公開されている
  必要があります（匿名 API で取得）。
- 更新中は「更新中… そのままお待ちください」画面を表示し、新バージョンで再起動したら自動で
  読み込み直します。90 秒で切り替わらない時は PC の黒いウィンドウを確認してください。
- Windows 専用機能です（macOS / 開発ビルドでは自動適用は無効＝手動ダウンロード）。
- **v1.0.0 → v1.1.0 の最初の 1 回だけは手動で exe を置き換え**てください（v1.0.0 に更新機能が
  無いため）。v1.1.0 以降は自動更新です。

### リリース手順（§B4）

1. 作業ツリーをクリーンにして `git tag vX.Y.Z`（`vMAJOR.MINOR.PATCH` 形式必須）。
2. `bash build/build-windows.sh` を実行（開発ビルドは `--dev`）。表示された `バージョン` が
   タグと一致することを確認。生成物は `build/AMO-koteihyo.exe` と `build/AMO-koteihyo.exe.sha256`。
3. GitHub リリースを作成し、次の **3 つのアセット**を添付（3 つ揃って初めて配布可）:
   - `AMO-koteihyo.exe`（本体）
   - `AMO-koteihyo.exe.sha256`（ハッシュ）
   - **`AMO-koteihyo-update.bat`** ← `build/かんたんアップデート.bat` を**この ASCII 名に変えて**アップロード
     （GitHub は非 ASCII のアセット名を受け付けないため。中身は同一。これが無いと使い方ガイドの
     ダウンロードボタンと `かんたんアップデート.bat` 本体が 404 になる）。
4. `/releases/latest/download/...` の各 URL が **HTTP 200** で取得できることを確認（本体・sha256・
   update.bat の 3 本とも）。例:
   ```sh
   for a in AMO-koteihyo.exe AMO-koteihyo.exe.sha256 AMO-koteihyo-update.bat; do
     curl -sI -o /dev/null -w "%{http_code} $a\n" -L \
       "https://github.com/zytakeshi/amo-koteihyo/releases/latest/download/$a"
   done
   ```
   3 本すべて 200 になってから告知・配布する。

## ファイアウォール（Windows の受信許可）

同一 LAN の iPad / iPhone から接続するには、この exe への受信許可（ファイアウォール規則）が
必要です。アプリは起動のたびに規則を検査し、無い／壊れていれば昇格（UAC）で 1 回だけ修復
します（UAC は 1 起動あたり最大 1 回）。規則名は exe パスから導く一意名
`AMO-koteihyo v2 <hash8>` で、移動・改名後の古い規則も検出・整理されます。

- 手動で許可したい時は、同じフォルダの **`ファイアウォール許可.bat` を管理者として実行**
  します（アプリとまったく同じ規則を作ります）。
- **ファイアウォール／ウイルス対策ソフトは切らないでください。** つながらない原因のほとんどは
  「このアプリを許可していないだけ」です。詳しい対処は `docs/使い方ガイド.html` の
  「ファイアウォールを再び有効にする手順」を参照してください。

## バージョン間のデータ互換とロールバック（重要）

v1.1.0 で JSON にタイムカード用の項目（`attendance` / `attendanceRev` / `tcConfig`）が
追加されました。

- **古い exe で新しいデータを開くと、これらの項目が保存時に失われます**（タイムカードの記録が
  消えます）。ロールバック（`.old` へ戻す・古い exe に戻す）した後は、必ず対応する時期の
  バックアップを `data/backup/` から復元してください。
- アプリは自動でバックアップを作ります:
  - **アップグレード前バックアップ**: 旧形式データを初めて新版で開く時に
    `data/backup/koteihyo.pre-v1.1.0.json`（元のバイトそのまま、上書きしません）。
  - **日次ローリングバックアップ**: 各日の最初の保存時に `data/backup/koteihyo-YYYYMMDD.json`
    （直近 14 世代を保持）。
- 自動更新のロールバックは exe を `AMO-koteihyo.exe.old` にリネームして戻します（更新前の版が
  残っています）。停電などで差し替えが中断した場合も、`.old` を元の名前に戻せば復旧できます。

## v1.0.0 → v1.1.0 の手動アップグレード（今回のみ）

v1.0.0 には自動アップデート機能がないため、v1.1.0 へ上げるときだけ手作業が必要です。
非技術者でも一人で実行できるよう、**ダブルクリック1つ**で完了する「かんたんアップデート」
を用意しています。動作の要点:

- 既存インストールを自動探索（**updater 自身のフォルダ → KFM 対応の実デスクトップ／OneDrive →
  %USERPROFILE% 再帰**の順、`data\koteihyo.json` を持つものを優先）。
- **先にダウンロード＋SHA-256 検証を完了**してから旧 exe に触れる（検証前は旧アプリを一切止めない・
  動かせる状態を維持）。検証成功後に限りアプリ終了 → バックアップ → 差し替え。
- フォルダ内の **両方の exe 名**（`AMO-koteihyo.exe` と `AMO工程表.exe`）をそれぞれ
  `<名前>.old-v1.0.0` として退避（改名のみ・削除なし。衝突時は `.2` 等を付与、実ファイル名は
  黒い画面に表示）。旧 `AMO工程表.exe` のショートカットが残っても、成功後に**同名の互換コピー**
  （新版）を置くので従来のショートカットもそのまま動く。
- 設置後に **`-PassThru` で起動して約3秒 生存確認**。すぐ落ちたら新 exe を `.failed` に退避し、
  退避した旧 exe を**元の名前へ**戻して起動し直す（戻せない場合のみ専用コード 21 で
  バックアップ名を表示して手動復旧を案内）。
- `data\` と `koteihyo.json` は**この更新ツールでは一切変更しない**（新版が初回起動時に
  `data\backup\koteihyo.pre-v1.1.0.json` を自動作成）。ダウンロードは PowerShell 5.1 でも
  `-TimeoutSec 120`／TLS1.2 で無限待ちを防止。

ファイル:

```
build/かんたんアップデート.bat        （リポジトリ内のファイル名）
AMO-koteihyo-update.bat               （GitHub Releases 上の配布名・ASCII）
```

手順を絵入りで説明したスタッフ向けガイド（ブラウザで開くだけ・印刷可）:

```
docs/アップデートガイド.html
```
